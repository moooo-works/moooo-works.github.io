# Frameasy（幀剪單）隱私權政策 {#zh}

**最後更新：2026 年 9 月 8 日**

[繁體中文](#zh) · [English](#en)

Frameasy（中文名稱「幀剪單」，以下稱「本應用程式」）由 **moooo_works** 開發。本政策說明本應用程式如何存取、處理、保存及刪除使用者資料。

## 核心原則

本應用程式是離線影片剪輯工具，不需要建立帳號，不含廣告、分析、追蹤或雲端同步功能，也不會將影片、照片、音訊、專案內容或裝置資料傳送給 moooo_works 或第三方伺服器。

## 本應用程式存取與處理的資料

為提供使用者主動要求的剪輯功能，本應用程式可能在裝置本機存取及處理：

- 使用者透過 Android 系統選擇器主動選取的影片、照片或音訊；
- 使用者主動啟動錄音功能並授予麥克風權限後，在裝置上錄製的旁白音訊；
- 專案名稱、文字內容、剪輯點、濾鏡、畫布及其他編輯設定；
- 預覽縮圖、媒體分析結果、代理檔與匯出暫存檔；
- 使用者匯出的影片與主動建立的專案備份檔。

以上資料只用於產生預覽、儲存專案、匯出影片或執行使用者選擇的功能。本應用程式不會將這些資料上傳、出售或提供給 moooo_works、廣告商、資料仲介商或其他第三方。

## 權限與系統功能

- **媒體選擇**：透過 Android 系統檔案選擇器，只存取使用者明確選取的檔案，不要求管理所有檔案的權限。
- **麥克風**：僅在使用者按下「開始錄音」並授予權限後，用於錄製影片旁白。錄音在裝置本機處理，不上傳。App 切到背景或錄音被系統中斷時會停止錄音，回到 App 不會自動重新啟動麥克風。使用者可在 Android 系統設定撤銷麥克風權限；拒絕權限不影響其他不需錄音的剪輯功能。
- **通知**：僅用於顯示影片匯出的本機進度與完成狀態；通知內容不會傳送至伺服器。
- **前景服務**：只在裝置本機執行影片匯出等耗時處理。
- **分享**：只有在使用者主動開啟 Android 分享面板並選擇接收者時，匯出檔案才會交給該接收者；接收者後續如何處理資料，受其自身政策約束。

本應用程式的上架版本不宣告 Android `INTERNET` 權限，因此沒有直接連線至網際網路或上傳使用者內容的能力。

## 本機保存、備份與刪除

- 專案資料與衍生檔案保存在 Android 應用程式沙箱內；來源媒體與匯出影片仍由使用者在原本選取的位置或系統媒體庫管理。
- 本應用程式已停用 Android 雲端自動備份及裝置移轉資料擷取，不會由應用程式資料備份機制將專案或媒體送至雲端。
- 刪除專案會移除該專案記錄；使用者可在設定中清除預覽、分析與匯出暫存資料。
- 解除安裝本應用程式會移除應用程式沙箱內的資料。已匯出至媒體庫、已分享或由使用者另行建立的備份檔不會自動刪除，須由使用者在相應位置自行管理。

錄音檔儲存在本應用程式的私有目錄。加入音軌前，使用者可試聽或重新錄音；重新錄音或確認捨棄時，未加入的錄音檔會被刪除。已加入音軌的錄音會保留供專案、復原／重做與匯出使用；刪除音軌或專案不代表立即刪除該音檔。清除應用程式資料或解除安裝會移除私有錄音；已匯出的影片、已分享的檔案或使用者建立的專案備份仍須自行管理。

## 資料安全

本應用程式使用 Android 應用程式沙箱及系統檔案選擇器限制資料存取範圍。由於本應用程式不收集或傳輸資料至我們的伺服器，moooo_works 不持有可供查閱、下載或刪除的使用者帳號或雲端資料。

## 兒童隱私

本應用程式不要求帳號，也不會刻意收集兒童或其他使用者的個人資料。

## 政策變更

如本應用程式未來的資料處理方式改變，我們會先更新本政策及 Google Play 的資料安全性聲明，並在本頁標示新的更新日期。

# Frameasy Privacy Policy {#en}

**Last updated: September 8, 2026**

Frameasy (also displayed as “幀剪單”, the “App”) is developed by **moooo_works**. This policy explains how the App accesses, processes, retains, and deletes user data.

## Core principle

The App is an offline video editor. It requires no account and contains no advertising, analytics, tracking, or cloud-sync functionality. It does not transmit videos, photos, audio, project content, or device data to moooo_works or third-party servers.

## Data accessed and processed by the App

To provide editing features explicitly requested by the user, the App may access and process locally on the device:

- videos, photos, or audio that the user explicitly selects through the Android system picker;
- narration audio recorded on the device after the user explicitly starts recording and grants microphone permission;
- project names, text, edit points, filters, canvas settings, and other editing choices;
- preview thumbnails, media-analysis results, proxy files, and temporary export files;
- videos exported by the user and project backup files the user explicitly creates.

This data is used only to generate previews, save projects, export videos, or perform a feature chosen by the user. The App does not upload, sell, or disclose this data to moooo_works, advertisers, data brokers, or other third parties.

## Permissions and system features

- **Media selection:** The App uses the Android system file picker and accesses only files explicitly selected by the user. It does not request permission to manage all files.
- **Microphone:** Used to record video narration only after the user taps “Start recording” and grants permission. Audio is processed locally and is not uploaded. Recording stops when the App moves to the background or the system interrupts recording. Returning to the App does not automatically restart the microphone. Users can revoke microphone permission in Android Settings. Denying permission does not affect editing features that do not require recording.
- **Notifications:** Used only for local video-export progress and completion status. Notification content is not sent to a server.
- **Foreground service:** Used only for long-running media processing performed locally on the device.
- **Sharing:** An exported file is passed to a recipient only when the user opens the Android share sheet and chooses that recipient. The recipient’s handling of the file is governed by its own policy.

The production version of the App does not declare the Android `INTERNET` permission, so it has no direct ability to connect to the internet or upload user content.

## Local retention, backup, and deletion

- Project data and derived files are stored in the Android app sandbox. Source media and exported videos remain under the user’s control in their selected location or system media library.
- Android cloud Auto Backup and device-transfer data extraction are disabled for the App, so project and media data are not included by the App’s backup configuration.
- Deleting a project removes its project record. Users can clear preview, analysis, and export cache data from Settings.
- Uninstalling the App removes data in the App sandbox. Media exported to the system library, files already shared, and backup files explicitly created by the user are not removed automatically and must be managed by the user in their respective locations.

Recordings are stored in the App’s private directory. Before adding a recording to an audio track, users can listen to it or record again. Recording again or confirming that a draft should be discarded deletes the unadded recording. Added recordings are retained for projects, undo/redo, and export; removing a track or project does not immediately delete its audio file. Clearing the App’s data or uninstalling it removes private recordings. Exported videos, shared files, and project backups created by the user must be managed separately.

## Data security

The App uses the Android app sandbox and system file picker to limit data access. Because the App does not collect or transmit data to our servers, moooo_works does not hold a user account or cloud data that can be accessed, downloaded, or deleted.

## Children’s privacy

The App does not require an account and does not knowingly collect personal data from children or other users.

## Changes to this policy

If the App’s data practices change, we will update this policy and the Google Play Data safety declaration before the change is released, and post a new revision date on this page.
