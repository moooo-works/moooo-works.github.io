# Privacy Policy / 隱私權政策

**Last updated / 最後更新：2026-05-06**

---

## English

### Overview

PikCards ("the App") is developed by moooo_works. This policy explains how we handle information when you use the App.

### Information We Collect

We do **not** collect, store, or transmit any personally identifiable information. The App does not require account registration.

### Data Stored Locally

Region map data downloaded by the user (SQLite database files) is stored in the App's **private internal storage** (`filesDir/regions/`). This data is only accessible by the App and is not shared with any third party.

### Network Access

The App connects to the internet solely for the following purposes:

| Connection | Purpose |
|---|---|
| GitHub Releases (`github.com`) | Fetching the region manifest and downloading region data files |
| OpenFreeMap (`tile.openfreemap.org`) | Loading map tile images |
| Google User Content (`lh3.googleusercontent.com`) | Loading postcard thumbnail images |

No personal data is transmitted in any of these connections.

### Permissions

| Permission | Purpose |
|---|---|
| `INTERNET` | Required to download region data and display map tiles and images |

The App does **not** request location, camera, microphone, contacts, or any other sensitive permissions.

### Third-Party Services

- **OpenFreeMap / OpenStreetMap** — Map tiles are provided by OpenFreeMap, which uses OpenStreetMap data. See [OpenStreetMap Privacy Policy](https://wiki.osmfoundation.org/wiki/Privacy_Policy).
- **Google User Content** — Postcard thumbnail images are loaded from Google's CDN (`lh3.googleusercontent.com`). These images are publicly accessible URLs embedded in the downloaded region data.

### Analytics & Advertising

The App does not include analytics SDKs. Advertising features are not currently active.

### Children's Privacy

The App does not knowingly collect any personal information from children under 13.

### Changes to This Policy

We may update this policy from time to time. The "Last updated" date at the top of this page reflects the most recent revision.

### Contact

For questions about this policy, contact: **moooo.works@gmail.com**

## 繁體中文

### 概述

PikCards（「本應用程式」）由 moooo_works 開發。本政策說明您使用本應用程式時，我們如何處理資訊。

### 我們收集的資料

我們**不**收集、儲存或傳輸任何個人識別資訊。本應用程式不需要帳號註冊。

### 本地儲存的資料

使用者下載的地區地圖資料（SQLite 資料庫檔案）儲存於應用程式的**私有內部儲存空間**（`filesDir/regions/`）。這些資料僅供本應用程式存取，不會與任何第三方共享。

### 網路存取

本應用程式僅因以下目的連線至網際網路：

| 連線對象 | 用途 |
|---|---|
| GitHub Releases（`github.com`）| 取得地區清單及下載地區資料檔案 |
| OpenFreeMap（`tile.openfreemap.org`）| 載入地圖圖塊圖片 |
| Google User Content（`lh3.googleusercontent.com`）| 載入明信片縮圖圖片 |

上述連線均不傳輸任何個人資料。

### 權限說明

| 權限 | 用途 |
|---|---|
| `INTERNET` | 下載地區資料及顯示地圖圖塊與圖片所必需 |

本應用程式**不**要求定位、相機、麥克風、通訊錄或其他敏感權限。

### 第三方服務

- **OpenFreeMap / OpenStreetMap** — 地圖圖塊由 OpenFreeMap 提供，使用 OpenStreetMap 資料。請參閱 [OpenStreetMap 隱私政策](https://wiki.osmfoundation.org/wiki/Privacy_Policy)。
- **Google User Content** — 明信片縮圖從 Google CDN（`lh3.googleusercontent.com`）載入，這些圖片為下載地區資料中內嵌的公開可存取網址。

### 分析與廣告

本應用程式不包含分析 SDK。廣告功能目前未啟用。

### 兒童隱私

本應用程式不會有意收集 13 歲以下兒童的個人資訊。

### 政策變更

本政策可能不定期更新。頁面頂部的「最後更新」日期反映最新修訂。

### 聯絡方式

如有關於本政策的問題，請聯絡：**moooo.works@gmail.com**
